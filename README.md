# CENTAURUS RASTREAMENTO

Site institucional responsivo para a Centaurus Rastreamento, em Castanhal, Pará.

## Arquivo principal
- `index.html`: site completo com CSS integrado, sem dependências externas.

## Publicar pelo GitHub Pages
1. Abra **Settings** do repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
5. Aguarde a publicação do GitHub Pages.
